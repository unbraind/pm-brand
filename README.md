# pm-brand

The Triplicate brand kit for [pm](https://github.com/unbraind/pm-cli): design
tokens, self-hosted fonts, the mark and icons that every pm surface shares
(pm-cli.unbrained.dev, pm-web, pm-gpt, pm-mcp, pm-search).

Status: under construction. The release is held until the kit is reviewed;
surfaces depend on an exact commit of this repository until then.

```css
@import "pm-brand/tokens.css";
body { background: var(--pm-paper); color: var(--pm-carbon); font-family: var(--pm-font-body); }
```

The token contract is in [CONTRACT.md](CONTRACT.md).
